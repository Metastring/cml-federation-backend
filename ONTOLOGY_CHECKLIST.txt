DATA MODELS (10 SQLAlchemy ORM Models)
================================================================================

✅ Domain (cml_domain)
   - UUID primary key
   - Unique constraint on domain_code
   - FK relationships to OntologyVersion
   - is_active flag
   - Created/updated timestamps

✅ OntologyVersion (cml_ontology_version)
   - UUID primary key
   - FK to Domain with CASCADE delete
   - Version code and status tracking (draft/active/deprecated)
   - Unique constraint on (domain_id, version_code)
   - FK relationships to Concept, OntologyChangeLog

✅ Concept (cml_concept)
   - UUID primary key
   - FK to OntologyVersion with CASCADE delete
   - Parent-child self-referencing relationship
   - is_abstract flag for concept types
   - Unique constraint on (ontology_version_id, concept_code)
   - FK relationships to Property

✅ Property (cml_property)
   - UUID primary key
   - FK to Concept with CASCADE delete
   - Data type specification
   - is_required and is_multivalued flags
   - Unique constraint on (concept_id, property_code)
   - FK relationships to PropertyConstraint

✅ PropertyConstraint (cml_property_constraint)
   - UUID primary key
   - FK to Property with CASCADE delete
   - JSON constraint_value for flexible storage
   - Constraint types: range, enum, regex, unit, geometry, vocab
   - Type field indexed for query performance

✅ Vocabulary (cml_vocab)
   - UUID primary key
   - Unique vocab_code
   - Description field
   - FK relationships to VocabularyTerm

✅ VocabularyTerm (cml_vocab_term)
   - UUID primary key
   - FK to Vocabulary with CASCADE delete
   - Parent-child self-referencing relationship
   - Unique constraint on (vocab_id, term_code)
   - Supports hierarchical taxonomies

✅ DatasetFieldMapping (cml_dataset_field_mapping)
   - UUID primary key
   - FK to Dataset (external), Concept, Property all with CASCADE delete
   - JSON transform_rule for data transformation
   - external_field_name and external_data_type
   - is_exposed flag for visibility control
   - Unique constraint on (dataset_id, external_field_name)

✅ DatasetConcept (cml_dataset_concept)
   - UUID primary key
   - FK to Dataset (external), Concept with CASCADE delete
   - Many-to-many association table
   - Unique constraint on (dataset_id, concept_id)

✅ OntologyChangeLog (cml_ontology_change_log)
   - UUID primary key
   - FK to OntologyVersion with CASCADE delete
   - Change type tracking (enum with 6+ types)
   - Audit trail: who changed, what, when
   - Ordered by changed_at descending
