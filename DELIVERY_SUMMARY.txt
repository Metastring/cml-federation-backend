                             QUICK START (3 STEPS)
================================================================================

STEP 1: Create Database (2 minutes)
  createdb ontology_db
  psql -d ontology_db -f SQL_CREATE_TABLES.sql

STEP 2: Configure & Install (3 minutes)
  source env/bin/activate
  cat > .env << 'EOFENV'
  DATABASE_URL=postgresql://postgres:password@localhost:5432/ontology_db
  DEBUG=True
  EOFENV
  pip install -r requirements.txt

STEP 3: Start Server (1 minute)
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

THEN: Open http://localhost:8000/docs in browser

TOTAL TIME: 6 minutes to running system ✅

================================================================================

10 Tables Created:
  1. cml_domain              - Ontology domains
  2. cml_ontology_version    - Versioned ontologies (draft/active/deprecated)
  3. cml_concept             - Concepts (with hierarchy support)
  4. cml_property            - Properties
  5. cml_property_constraint - Validation rules (JSON storage)
  6. cml_vocab               - Controlled vocabularies
  7. cml_vocab_term          - Vocabulary items (with hierarchy)
  8. cml_dataset_field_mapping - External data mappings
  9. cml_dataset_concept     - Dataset associations
  10. cml_ontology_change_log - Audit trail

23+ Indexes for performance
FK Relationships with CASCADE delete
UUID primary keys
Timestamp tracking (created_at, updated_at)
